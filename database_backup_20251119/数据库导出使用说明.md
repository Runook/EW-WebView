## 📝 手动设置方法（如果自动脚本失败）

如果 `quick_setup.sh` 遇到问题，可以手动执行：

```bash
# 1. 创建数据库
createdb ewlogistics

# 2. 导入表结构
psql -d ewlogistics -f complete_database_dump.sql

# 3. 导入每个表的数据
for file in *_data.csv; do
    table=$(echo $file | sed 's/_data.csv//')
    echo "导入 $table..."
    psql -d ewlogistics -c "\COPY $table FROM '$file' WITH CSV HEADER;"
done

# 4. 重置序列（重要！）
psql -d ewlogistics << 'EOF'
DO $$
DECLARE
    r RECORD;
BEGIN
    FOR r IN SELECT tablename FROM pg_tables WHERE schemaname = 'public' LOOP
        EXECUTE 'SELECT setval(''' || r.tablename || '_id_seq'', COALESCE((SELECT MAX(id) FROM ' || r.tablename || '), 1))';
    END LOOP;
END $$;
EOF

# 5. 验证
psql -d ewlogistics -c "SELECT COUNT(*) FROM users;"
```

## 🆘 常见问题

### Q1: pg_isready 命令找不到
**A**: PostgreSQL 未正确安装或未添加到 PATH
```bash
# macOS
export PATH="/opt/homebrew/opt/postgresql@17/bin:$PATH"
```

### Q2: createdb 权限不足
**A**: 使用 postgres 用户
```bash
sudo -u postgres createdb ewlogistics
```

### Q3: 导入数据时编码错误
**A**: 设置正确的编码
```bash
createdb -E UTF8 ewlogistics
```

### Q4: 序列值不正确，插入数据失败
**A**: 手动重置序列
```bash
psql -d ewlogistics
SELECT setval('users_id_seq', (SELECT MAX(id) FROM users));
-- 对其他表重复此操作
```

### Q5: test_connection.js 找不到 pg 模块
**A**: 安装依赖
```bash
npm install pg
```
