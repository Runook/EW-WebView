🚀 在新电脑上的使用步骤
═══════════════════════════════════════════════════════════════

1️⃣  传输文件到新电脑
   - 使用U盘、AirDrop、网盘或SCP
   - 文件: ewlogistics_db_export_20251119_140309.tar.gz

2️⃣  解压文件
   tar -xzf ewlogistics_db_export_20251119_140309.tar.gz
   cd database_export

3️⃣  安装 PostgreSQL (如果未安装)
   macOS:  brew install postgresql@17
   Ubuntu: sudo apt install postgresql-17

4️⃣  运行一键设置
   ./quick_setup.sh
   
   (脚本会自动完成所有设置！)

5️⃣  配置项目
   - 编辑 backend/src/config/database.js
   - 编辑 employee-service/src/config/database.js
   - 设置 host: 'localhost'

6️⃣  测试连接
   npm install pg
   node test_connection.js

7️⃣  启动服务
   cd backend && npm start
   cd employee-service && npm start
   cd frontend && npm start
