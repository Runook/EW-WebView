## 四、合作模式

我们提供灵活多样的合作方式，可根据达人的内容风格和粉丝量级定制方案：

### 模式 A：品牌推广（适合所有量级达人）

- 在视频中提及或展示 Welogx 平台
- 口播介绍平台核心功能
- 视频描述区放置专属推广链接
- **合作费用：面议（根据粉丝量和播放量）**

### 模式 B：深度测评（适合中腰部及以上达人）

- 制作 Welogx 平台使用体验/测评视频
- 展示平台核心功能的实际操作流程
- 分享真实使用感受和推荐理由
- **合作费用：面议 + 平台积分奖励**

### 模式 C：长期合作大使（适合头部达人或垂直领域 KOL）

- 成为 Welogx 品牌合作伙伴
- 定期产出内容（每月 1-2 条）
- 专属推广码 + 佣金分成（CPA/CPS）
- 优先体验新功能，参与产品共创
- **合作费用：月度固定费 + 推广佣金**

### 模式 D：佣金分成（适合所有达人，零门槛）

- 通过专属推广链接/推广码推广
- 用户通过链接注册并充值后，达人获得佣金分成
- 无固定合作费，纯按效果付费
- **佣金比例：面议（充值金额的 10%-20%）**
